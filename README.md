# Insegnamento di Bioinformatica - materiale integrativo

This branch publishes teaching materials through GitHub Pages.

Add one top-level folder per material unit. Each folder is shown as one card on
the index page.

- If the folder contains `index.html`, the card opens that page.
- Otherwise, if the folder contains a PDF file, the card opens the first PDF in
  alphabetical order.

The GitHub Actions workflow rebuilds `materials.json` and deploys the page on
every push to this branch.
